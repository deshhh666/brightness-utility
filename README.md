# Яркость монитора

Портативная утилита для Windows 10 и Windows 11. Запустите **Brightness.exe** и перемещайте ползунок нужного монитора. Яркость меняется при перемещении с небольшой задержкой, без кнопки «Применить». Клавиши стрелок меняют значение на 1%, Page Up / Page Down — на 10%.

Каждому монитору соответствует отдельная карточка. Программа читает текущую яркость при запуске и обновлении. Подключение экранов, изменение конфигурации и выход из сна запускают автоматический повторный поиск с задержкой 1,2 секунды и дополнительными попытками через 4 секунды. Кнопка **Обновить** остаётся доступна для ручного поиска, например после включения DDC/CI в меню монитора.

## Управление

- **Трей:** левый щелчок по значку возле часов открывает компактное окно с ползунками. Правый щелчок — меню с пресетами, открытием основного окна и командой **Выход**. Крестик и сворачивание основного окна скрывают его в трей; программа продолжает работать. Windows может поместить значок под стрелку скрытых значков.
- **Имена:** нажмите кнопку с карандашом в карточке или дважды щёлкните по названию. Пустая строка возвращает стандартное название. Имена привязаны к идентификатору экрана, а не к его порядку в списке. При смене порта или драйвера Windows может назначить другой идентификатор.
- **Общая яркость:** включите **Все мониторы**. Общий ползунок устанавливает одно значение всем доступным экранам; отдельные ползунки в этом режиме также связаны. Снятие флажка возвращает независимую регулировку. Включение флажка само по себе не меняет яркость.
- **Горячие клавиши:** **Ctrl + Alt + PgUp** увеличивает яркость каждого экрана на 5%, **Ctrl + Alt + PgDn** уменьшает на 5%. **Ctrl + Alt + колёсико** работает глобально, даже когда окно скрыто. Колёсико над любым ползунком меняет его на 5% за деление. Глобальные команды сохраняют разницу между экранами, пока значения не достигнут 0 или 100%. Если сочетание занято другой программой, внизу окна появляется сообщение.
- **Пресеты:** **День**, **Вечер**, **Ночь** по умолчанию задают 80%, 40%, 15%. Настройте экраны отдельно и нажмите кнопку сохранения со стрелкой вниз справа от нужного пресета. Пресет хранит собственное значение для каждого монитора и восстанавливает их даже при включённой общей регулировке. Впервые подключённый экран получает стандартное значение пресета.
- **Автозапуск:** флажок **Запускать с Windows** добавляет запуск в трей при входе текущего пользователя в Windows. Снятие флажка удаляет запись. Используется только значение `BrightnessUtility` в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, без прав администратора. После включения не переносите EXE в другую папку; если переносите, выключите и снова включите флажок из новой папки. Сам по себе запуск утилиты не включает автозапуск.

Повторный запуск EXE открывает окно уже работающей копии. Аппаратная яркость остаётся установленной после выхода из программы.

По умолчанию включена **тёмная тема**. Флажок «Тёмная тема» внизу окна переключает её на светлую и обратно без перезапуска. Выбор сохраняется для текущего пользователя в `%LOCALAPPDATA%\BrightnessUtility\theme.txt`.

Названия, пресеты и состояние общей регулировки сохраняются в `%LOCALAPPDATA%\BrightnessUtility\settings.xml`.

Ожидание перед первой командой ползунка уменьшено с 90 до 20 мс. Во время непрерывного перетаскивания обновления продолжаются; после завершения команды монитору сразу отправляется последнее выбранное значение. Промежуточные позиции не накапливаются в очереди. Реальная скорость также зависит от времени ответа самого монитора.

## Требования

- Windows 10 / 11 со встроенным .NET Framework 4.5 или новее; на обычных установках этих Windows он уже есть.
- Внешний монитор с поддержкой DDC/CI, включённой в меню самого монитора. Подключение через некоторые переходники, док-станции и удалённый рабочий стол может не пропускать команды.
- Встроенные экраны управляются через WMI, если драйвер предоставляет соответствующий интерфейс.

Утилита меняет аппаратную яркость, без затемняющей накладки. Если монитор или драйвер не предоставляют управление, ползунок недоступен. В режиме HDR и некоторых режимах изображения монитор может блокировать регулировку. Если команда не принята, причина отображается под ползунком.

Установка, интернет и права администратора не требуются. Для переноса достаточно скопировать `Brightness.exe` и `Brightness.exe.config`. Запись автозапуска изменяется только при переключении соответствующего флажка.

## Сборка и диагностика

Исходный код — `Brightness.cs`, `Features.cs` и `Design.cs`, без сторонних библиотек. Собрать из Windows PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Диагностика без изменения яркости:

```powershell
.\Brightness.exe --diagnose diagnostics.txt
```

`--smoke-test` открывает окно, обнаруживает реальные экраны, проверяет тёмную/светлую тему, компактное окно и общий регулятор. Сохраняет `smoke-test.png`, `smoke-test-light.png`, `smoke-test-tray.png` и `smoke-test.txt` рядом с программой и закрывается, без записи яркости, автозапуска или пользовательских настроек. `--tray` запускает обычную копию в трее.

`tests/InteractionCheck.cs` проверяет сохранение темы во временной папке, цвета карточки и ползунка, обновление реальной яркости при непрерывном движении и применение конечного значения. Временно меняет яркость на 1–2%, затем восстанавливает точное исходное значение. Сборка и запуск из папки проекта:

```powershell
& "$env:WINDIR\Microsoft.NET\Framework64\v4.0.30319\csc.exe" /nologo /target:exe /platform:anycpu /codepage:65001 /main:InteractionCheck /out:tests\InteractionCheck.exe /reference:System.Windows.Forms.dll /reference:System.Drawing.dll /reference:System.Management.dll /reference:System.Xml.dll /reference:Accessibility.dll /resource:assets\Brightness.ico,Brightness.ico Brightness.cs Features.cs Design.cs tests\InteractionCheck.cs
& .\tests\InteractionCheck.exe
```

`tests/FeaturesCheck.cs` проверяет сохранение названий и пресетов, включение/выключение автозапуска с восстановлением исходной записи, общую регулировку, разные значения в пресете, синхронизацию окна трея, колёсико, регистрацию глобальных клавиш и обработку сообщения горячей клавиши. Событие выхода из сна имитируется без реального перевода компьютера в сон: проверяется повторное обнаружение экранов и сохранение имён. Во время проверки используется реальная яркость; исходные значения восстанавливаются. Для аппаратной части нужны два монитора с DDC/CI. Запуск:

```powershell
& "$env:WINDIR\Microsoft.NET\Framework64\v4.0.30319\csc.exe" /nologo /target:exe /platform:anycpu /codepage:65001 /main:FeaturesCheck /out:tests\FeaturesCheck.exe /reference:System.Windows.Forms.dll /reference:System.Drawing.dll /reference:System.Management.dll /reference:System.Xml.dll /reference:Accessibility.dll /resource:assets\Brightness.ico,Brightness.ico Brightness.cs Features.cs Design.cs tests\FeaturesCheck.cs
& .\tests\FeaturesCheck.exe
```

Используются официальные API Windows: [DDC/CI SetMonitorBrightness](https://learn.microsoft.com/en-us/windows/win32/api/highlevelmonitorconfigurationapi/nf-highlevelmonitorconfigurationapi-setmonitorbrightness), [SetVCPFeature](https://learn.microsoft.com/en-us/windows/win32/api/lowlevelmonitorconfigurationapi/nf-lowlevelmonitorconfigurationapi-setvcpfeature), [WmiSetBrightness](https://learn.microsoft.com/en-us/windows/win32/wmicoreprov/wmisetbrightness-method-in-class-wmimonitorbrightnessmethods).

## Оформление и значок

Основное окно и быстрое окно из трея используют общую систему: графитовые поверхности, янтарные ползунки, спокойные подписи, единые отступы и светлая тема. Значения яркости выровнены справа. Кнопки, переключатели и ползунки имеют состояния фокуса; стрелки, Page Up / Page Down, Home / End работают на ползунке. Ошибку можно прочитать целиком во всплывающей подсказке над подписью.

Иконка «экран с солнцем» встроена в EXE и используется в окне, панели задач и трее. Утилите не нужен внешний файл иконки; ICO содержит размеры от 16 до 256 px. Для пересоздания исходника: `python tools/make_icon.py` (только для разработки, требуется Pillow). Обычная сборка `build.ps1` использует уже готовый значок.

Проверки нового интерфейса: `powershell -NoProfile -ExecutionPolicy Bypass -File tests/run-checks.ps1`. Параметр `-Hardware` также запускает проверки реальных мониторов, горячих клавиш, пресетов, автозапуска и трея с восстановлением исходной яркости и настройки автозапуска.
